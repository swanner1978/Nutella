# Glossaire du domaine

| Terme | Definition |
|-------|------------|
| **CanonicalModel3D** | Modele 3D normalise (STEP/STL) — source de verite pour calculs |
| **ViewProjectionCache** | Vues 2D côté/dessus (Side/Top) — visualisation uniquement |
| **ContactResult** | Resultat simulation contact 3D avec coverage_score |
| **DesignSpace** | Espace paramétrique du racloir |
| **JarCanonicalModel** | Geometrie 3D interne du pot Nutella |
| **ComputeEngine** | Moteur de calcul (contact, metriques) |
| **VisualizationEngine** | Moteur de visualisation (projection read-only) |
| **OptimizationEngine** | Moteur d'optimisation (via ComputeEngine) |
