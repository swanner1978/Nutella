# FDM Guidelines

Parametres par defaut (`configs/default.yaml`) :

| Parametre | Valeur | Description |
|-----------|--------|-------------|
| `min_wall_thickness_mm` | 1.2 | Epaisseur minimale paroi |
| `max_overhang_angle_deg` | 45 | Angle surplomb max sans support |
| `clearance_compensation_mm` | 0.15 | Jeu imprime vs nominal |

Implementation future : `engines/compute/fdm_printability.py`.
